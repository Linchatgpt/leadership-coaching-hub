# 第三章深入閱讀精修設計

## 目標

在不改變六節骨架、三個文章工具與總結提要的前提下，讓第三章從完整的概念稿提升為案例、工具與管理判斷互相支撐的學習章節。

## 核准修法

1. 以軟體公司轉向訂閱模式為貫穿案例，分別呈現願景宣告、訊號整理、角色期待、未來圖像、責任改變與一個月後的混合結果。
2. 用「看見訊號 → 找到共同期待 → 連回今日選擇」串連三個既有工具。
3. 第四節只處理可見的未來工作情境；第五節只處理角色、權限、能力與責任。
4. 強化作者判斷：共同願景是否成立，要看成員的聲音是否曾改變一項選擇，而不只看口頭認同。
5. 減少成群的對比句型與平均段落節奏，保留事件、限制與未完成狀態。
6. 總結提要兼具概念回顧與主管檢查問題。

## 固定限制

- canonical 檔案維持 `reference_materials/chapters/chapter_03/02_deep_reading_draft.md`。
- 只修改文字稿，不修改 HTML。
- 導言 180–260 字且只有一段；第一節緊接其後。
- 渲染文字一般目標至少 5,000 字。
- 保留 6 個主段落、3 個分散工具與最後的總結提要。
- 學習者文字不提來源書籍、作者或正式量表。

## 驗收

- 案例至少在四個主段落中繼續發展，且結果不是完美成功。
- 三個工具各自對應整體路徑的一步，並以案例示範。
- 第四、第五節不再重複相同的「把願景落地」論述。
- 無來源不明的數字、研究結論或企業實名。
- 內容分析、文章檢查與 Markdown 渲染結構檢查完成。
